Slowcial

Viewport-sized breathing room inside Instagram’s infinite feed — friction without a blocker.

The problem

Infinite feeds collapse distance between items until scrolling becomes automatic. Most “solutions” either block the site or wrap the habit in wellness language. Slowcial tests a narrower idea: keep the feed, change the spacing.

The experiment

On Instagram, Slowcial injects CSS that adds a configurable viewport multiple (1×, 1.5×, 2×) between posts. A floating session widget tracks elapsed time and posts centered in the viewport. Enable/disable and gap size sync through browser.storage.sync.

  • Target Instagram (Firefox-first, MV3)
  • Mechanism Content-script CSS + observers
  • Controls Gap preset + enable toggle
  • Session Viewed-post count + elapsed time

Technical highlights

  1. Third-party DOM augmentation Spacing targets Instagram’s feed articles with conservative selectors and graceful no-op when markup shifts.
  2. Lifecycle-safe injection A MutationObserver re-applies the style tag and session widget if SPA navigation removes them — without stacking duplicate listeners.
  3. Visibility-aware counting Viewed posts are deduped with a WeakSet and attributed when an article is centered in the viewport (scroll/resize rAF + light interval).
  4. Minimal privilege surface Only storage + Instagram host permissions. No analytics, no content scraping, no account access.
  5. UI isolation Injected chrome uses namespaced IDs/classes and high z-index; host page styling is limited to intentional margin rules.

Current status

Demonstrable prototype for Instagram on Firefox. Instagram’s DOM is a moving target — selectors may need occasional updates.

Full readiness notes live in the repo’s SHOWCASE_STATUS.md.

Run it locally

  1. Clone martondob/slowcial.
  2. Firefox → about:debugging#/runtime/this-firefox
  3. Load Temporary Add-on → select extension/manifest.json
  4. Open Instagram, set a gap in the popup, scroll the feed.

Temporary add-ons unload when Firefox restarts. No store packaging yet.
